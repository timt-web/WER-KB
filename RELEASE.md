# WER-KB v0.2.0

This release keeps WER-KB as a selective catalog for post-analytical germline WES/WGS interpretation. Stages, evidence types, and resource identity follow `schemas/resource_catalog_schema.md`. The JSON catalog, the rationale notes, and the workflow page match the tables in `data/`.

External-resource metadata still has to be checked at the point of use whenever `reverify_at_use` is `yes`. See `CHANGELOG.md` for the v0.1.0 baseline and the v0.2.0 corrections.
