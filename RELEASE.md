# WER-KB v0.3.0

This release aligns the catalog with the manuscript *Clinical WES/WGS Variant Interpretation and Prioritization: An Evidence-Based Framework for Resource Selection and Integration* and with Table 1. Analytical functions, evidence types, workflow positions, and key limitations use that table. The core representative set is limited to the resources named there.

External-resource metadata still has to be checked at the point of use whenever `reverify_at_use` is `yes`. See `CHANGELOG.md` for earlier releases.
