# Changelog

## v0.3.0 — 2026-10-14

- Cited the manuscript under its current title and described WER-KB as the updateable implementation and documentation layer for resource selection and evidence integration.
- Aligned analytical functions, primary purposes, evidence types, workflow positions, and key limitations with Table 1, and recorded the supporting citation for each resource.
- Limited the core representative set to the resources named in Table 1. Retired MSeqDR-QM and the separate Richards et al. 2015 catalog row. Added the ACMG points to consider on reevaluation and reanalysis.
- Mapped ClinGen to reporting and reinterpretation, regulatory and structural resources to stages 7–9, and GeMSTONE to stages 5–9, context dependent.

## v0.2.0 — 2026-10-10

- Extended the catalog schema with controlled evidence types, maintenance states, genome-build tokens, complementary resource identifiers, and a separate recheck-at-use flag.
- Aligned workflow stages with each stage's scientific question, including mitochondrial scope for MSeqDR-QM, splicing versus protein-structure resources, and separation of ClinGen validity curation from ClinGen specifications.
- Corrected resource identity and URLs where an entry pointed at a different resource, and recorded releases for fixed documents and data sets.
- Added the JSON catalog, per-resource rationale notes, and a stage-by-stage workflow page.
- Added catalog validation, a pre-release URL check, and continuous integration.

## v0.1.0 — 2026-09-28

Initial public-ready implementation of WER-KB based on the associated methods-oriented framework manuscript.

- Added a catalog of representative resources across 13 analytical functions and 11 workflow stages.
- Added standardized selection rationales, appropriate-use guidance, interpretation boundaries, limitations, and complementary resources.
- Added workflow mapping, dependency guidance, governance policy, schema, and contribution template.
- Version/release values for external resources were left for verification at the point of use.
